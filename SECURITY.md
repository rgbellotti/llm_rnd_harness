# Reporting a vulnerability

Not verified for production use.

Please report vulnerabilities **privately** through GitHub's private
vulnerability reporting: open the repository's **Security** tab and
choose **Report a vulnerability** (Security Advisories). Do not open a
public issue for a security problem.
 
Include the commit you tested, your OS, the provider/model in use, and
steps to reproduce. This is a hobby project maintained in spare time, so
there is no guaranteed response time, but reports are read and
acknowledged as soon as possible.
