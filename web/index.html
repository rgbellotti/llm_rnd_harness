How to structure selected context

This harness uses a context curation approach, where it's important to delineate the information. Use these structure tags to edit a session history, and then resend it as the next prompt to the model using Generate.

==== PROMPT ====
(original prompt text)
==== THINKING (round 1) ====
(model reasoning)
==== RESPONSE (round 1) ====
(model answer text)
==== TOOL CALL run_cmd (round 1) ====
(arguments)
==== TOOL RESULT (round 1) HID: 243 ====
(command output)
==== TOOL RESULT (round 1) HID: 243 ====
[ctx compacted]
---- Uploaded File 'notes.txt' ----
(file contents)
---- EOF 'notes.txt' ----

Curate a round, a response, or a session appends that text here with the same labels.

  • Save saves prompt to a file.
  • Compact replaces the selection with [ctx compacted]. The header keeps HID, the history row id. Selecting the marker recalls that row. Copy stays a browser key.
  • Clear clears the prompt.
  • Restore restores the last autosave (or Clear).

Token/time metrics available in JSON/HTML exports, but not added to assembled context. Per-call timing embedded in tool results is kept.
